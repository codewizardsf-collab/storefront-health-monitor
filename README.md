# Storefront Health Monitor

Node ecommerce project for monitoring checkout conversion, payment failure rates, inventory accuracy, webhook lag, and storefront readiness across multiple brands.

## Resume Fit

- Shopify Plus/multi-storefront infrastructure.
- Checkout and payment reliability dashboards.
- Campaign launch readiness checks.

## Current Scope

- Node domain module for storefront health scoring.
- Built-in tests using `node --test`.

## Production Next Steps

- Add Shopify Admin API adapter.
- Add Redis-backed webhook lag tracking.
- Add Datadog/OpenTelemetry metrics export.
